# Smart Shop Manager Pro — مدير المحل الذكي

تطبيق أندرويد احترافي (Offline-First) لإدارة المحلات التجارية باللغة العربية وبواجهة RTL داكنة، مبني بـ **Kotlin + Jetpack Compose + Room (SQLite)**.

## الميزات الرئيسية
- **المبيعات ونقطة البيع (POS):** شبكة منتجات سريعة، بيع بالعلبة أو بالوحدة المفردة، إخفاء تلقائي للمنتجات النافدة، سلة متعددة المنتجات، فواتير نقدية أو بالكريدي، ومنع تكرار الفواتير مع Rollback ذري كامل عند أي خطأ.
- **الإدخال السريع:** يدعم الأوامر المختصرة مثل `+5s rym`، `+1* rym`، `-علبة rym`، `-5 سجارة rym`.
- **المنتجات والمخزون:** إدارة كاملة للمنتجات، جرد الصباح الجماعي، تنبيهات انخفاض ونفاد المخزون، وسجل حركات مخزون (Inventory Ledger) مع منع المخزون السالب.
- **الزبائن والكريدي:** إدارة الزبائن، تسجيل الديون، التسديد الجزئي والكامل، التسويات القابلة للتتبع، وكشف حساب تفصيلي لكل زبون.
- **المصاريف والمشتريات:** فصل تام بين المصاريف التشغيلية ومشتريات البضاعة (دون ازدواج في حساب صافي الربح).
- **التقارير والصندوق اليومي:** تقارير يومية/أسبوعية/شهرية ومخصصة، تتبع الرصيد النقدي الفعلي منفصلاً عن الإيرادات والأرباح، وتحليلات المنتجات وأعمار الديون.
- **الأمان والنسخ الاحتياطي:** صلاحيات المالك والبائع، قفل PIN مشفر بـ SHA-256 + Salt، وتصدير/استعادة نسخة احتياطية كاملة بصيغة JSON عبر منتقي ملفات أندرويد (SAF) دون أذونات تخزين واسعة.

## المتطلبات والبناء المحلي (Build & Test)
- Android Studio (JDK 11+)
- Android SDK 36 (يعمل على أجهزة Android 7.0 / API 24 فأحدث)

```bash
# بناء ملف APK للتجربة
gradle :app:assembleDebug

# تشغيل الاختبارات الآلية (14 اختباراً لوحدة البيانات والمنطق المالي)
gradle :app:testDebugUnitTest
```

> **ملاحظة:** لا يتم تضمين ملفات `.env` أو `debug.keystore` في المستودع حفاظاً على الأمان (مدرجة في `.gitignore`).
